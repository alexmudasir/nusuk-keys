# Nusuk Keys

A community website for sharing Nusuk keys.

## What it does

- Lists Nusuk keys shared by the community, with copy-to-clipboard
- Search and filter
- Marks keys as claimed, saved in the browser

## Live demo

https://nusukkeyss.netlify.app/

## Notes

- Keys are shared by the community; availability is not guaranteed.
- The claimed count is stored per browser.
